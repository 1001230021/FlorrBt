# 文字排版与图鉴介绍核查

## 文字排版

- DOM、花瓣名称测量、HUD 与场景文字使用同一字体栈。保留 Ubuntu 英文字体，补充中文无衬线字体回退；声明字体资源的字重，避免重复合成粗体。
- `render_text.js` 原先以字形包围盒居中缓存文字，直接绘制却使用 Canvas 的文字基线。现在缓存按调用方的基线测量、绘制和定位，并保留字形左侧伸出量。
- 文字缓存键加入字体族和基线；字体加载完成后清空旧字形缓存。
- 删除面板标题独立的延时缩放与位移。标题和关闭按钮跟随整个面板运动。
- 设置、背包搜索、合成说明与按钮增加可读字号下限；标题给关闭按钮留出空间，选择控件和按钮给文字留出足够高度。
- 卡片名称增大行高与短名称字号，并继续使用实际测量限制长名称宽度。
- 手机合成表格保持稀有度列，通过横向滚动查看；锻造列表继续按可用宽度排列。

## 验证

- `tools/text_render_browser.mjs` 比较真实浏览器直接绘制与缓存绘制：3 组字体、3 组中英文本、6 种基线、3 种水平对齐，共 162 组；本机最大边界误差 1px。另验证缓存复用与字体加载后的失效。
- `tools/test_codex_ui.mjs` 检查图鉴节点复用、滚动条保留、介绍缓存、浮窗内事件冒泡不会触发关闭，以及掉落卡和概率成对排列。
- UI 布局、移动端、面板动画、卡片、合成天赋、渲染、账户凭据和功能权限的相关回归通过。
- `node tools/check_reference_client.mjs --live --original` 使用隔离账户、数据目录及随机端口，完成移动、装备拖拽、合成、天赋购买、聊天、战斗、面板切换、复活和重连。
- 人工布局数据覆盖 4 种视口、3 种语言、5 类面板，共 60 组；另复核 12 组图鉴浮窗停留阅读。截图和几何核查保存在 `artifacts/text-ui-review/`，不写入正式账户。
- 没有新增模块循环依赖或反向导入 `game.js`。

本轮不修改服务端玩法，没有生成部署包或提交、推送。浏览器回归仍会记录原有的 `eou_pheromone.svg` 缺失提示；性能数据包含截图和像素对照操作，不作为性能基准。
