# 紧凑界面与菜单花瓣动画

## 界面调整

- 账户面板从 330px 收到 280px。首页保留账户名、“账号绑定”与退出；Discord、QQ、邮箱位于二级页，支持返回按钮和 Esc 返回。
- 取消邮箱绑定回到原来的账户二级页，包括游戏内打开账户的情况。原有认证、绑定、自动预登录与入场条件沿用现有流程。
- 桌面面板宽度：背包 404→360、合成 612→536、天赋 654→576、图鉴 600→528、设置 480→400；同步收紧高度、边框、内边距和卡片尺寸。
- 背包和手机端卡片列表靠左、固定间距排列；手机保留基本触摸操作面积。
- 图鉴掉落区每格固定 42px、列间距 4px，卡片与概率一起换行；浮窗由 420px 收到 340px。单张、少量卡片也从左侧开始，不再平分整行宽度。

## 视频依据和动画

对用户提供的 `QQ20261101-001700.mp4` 的 2.0～16.4 秒菜单片段按 10 FPS 采样，分析 145 帧。跟踪到 25 条较稳定的轨迹：

- 可识别花瓣水平速度约 74～180px/s，方向为从左向右。
- 纵向轻摆振幅约 20px，拟合频率约 0.16Hz。
- 可稳定估计朝向的长条花瓣约 172°/s，即约 3rad/s；圆形与近对称花瓣不用于可靠角速度估计。

原实现是固定数组向下循环，这轮删除该实现。新粒子按时间持续出生，各自抽取库存物品、大小、速度、角速度和相位；按用户要求让角速度独立变化，并以测得的旋转速度为基准。默认约每 0.4～0.6 秒生成一个，根据视口高度调整密度，离开右侧后销毁。

生成时刻精确积分，避免不同刷新率改变出生数量和轨迹。设置→画面中的“开始页动态花瓣”只有开、关两种状态：默认动态显示，关闭则清空并隐藏花瓣。菜单花瓣不跟随系统的减少动态效果设置，不提供静态模式。空背包或退出账户时没有装饰花瓣。仍按真实 Inventory 数量加权，没有演示花瓣兜底。位图缓存只保留当前粒子使用的图像，沿用原来的单一渲染循环。
