# NPC 背包作用域

状态：已实现独立临时背包、预置装备恢复、保留会话重连和热重载，三个 NPC 专项及预置 Unique 隔离检查通过。新的经济请求协议已接入同一作用域，迟到的请求不能操作替换后的背包或身体。用户最新选择是“玩家和 NPC 背包完全分离，NPC 背包先做临时”；它取代先前的借用玩家花瓣方案。

应区分三个概念：登录身份用于认证/重连；玩法进度作用域用于正式或沙盒的成长规则；当前背包作用域用于装备、合成、掉落拾取和物品同步。控制 NPC 不应改写登录账号，也不应把整个账号进度字段都当成背包键。

当前 NPC 容器使用带随机 128 位后缀的独立作用域键；每次新的控制关系分配新键，避免冷启动后计数器重用。它只进入热重载快照，不进入正式账户存储；快照恢复保留原键。网络请求同时携带背包键和受控身体身份，旧身体的请求不能操作新的身体。

- 玩家花朵使用所在玩法的背包；普通世界为正式背包，沙盒为已有临时作用域。
- 控制 NPC 时启用独立临时背包。NPC 花朵的当前预置卡进入该容器的装备栏，额外背包初始为空；预置装备在世界侧另存恢复布局。
- 该控制期间的装备/卸下/合成/副槽/拾取只读写 NPC 容器。正式装备与背包保持封存，不向 NPC 容器借出物品。
- Unique 的正式归属操作只允许正式背包；NPC 临时花瓣不写全服唯一归属账本。
- 释放控制后丢弃临时背包，恢复 NPC 原布局并按通常装备加载规则重新加载；随后恢复原 AI。无默认 AI 或默认 PlayerController 时，按非击杀移除。
- 多节生物的任意部位统一附身到根；同一条生物内部重复选择部位不会重建临时背包。旧会话单独控制过的附属体节，在释放时恢复跟随根，不适用独立 NPC 的无 AI 移除规则。
- 真正死亡保持死亡结果，不因归还控制而复活。临时背包随实际控制作用域结束清理。
- 短暂断线保留会话时保留临时容器；真正注销/超时移除会话时结束它。热重载需保存当前临时容器、请求回执、恢复布局及完整控制身份。
- 同一身体跨世界时明确保留其控制容器；更换受控身体创建新的容器身份。旧请求不能因数字实体 ID 重用而作用到新身体。

网络基线必须告知当前物品作用域，客户端在切换时清理旧的待确认装备意图。临时身份用面向玩家的说明展示，不能把内部账号前缀直接露在 UI 中。

重点回归：预置 Unique 卸下不影响正式账本；正式材料不能在 NPC 合成中消耗；NPC 拾取物不进入正式包；多次附身/退出不复制物品；短断线、会话销毁和热重载；沙盒中的 NPC 控制；带旧作用域的迟到请求。
