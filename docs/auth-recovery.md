# 登录恢复凭证

恢复令牌从协议 1.0.6 引入，当前协议为 **1.0.9**，前后端必须一起更新。1.0.8 新增账户菜单的独立登录、注册和开始游戏请求，1.0.9 增加账户绑定与客户端功能清单。IP 只保留为登录地址记录，不再授权免密码登录；历史账户文件中的 `trusted_ip` 字段为兼容数据保留，认证过程不读取它作为凭证。

首次登录或注册验证密码后，认证 worker 生成 32 字节系统安全随机数作为恢复令牌。服务器只保存 Argon2id 验证摘要、客户端随机设备标识及到期时间，原始令牌只通过成功认证响应发给客户端。摘要同时绑定账户的密码哈希，改密码后旧令牌无法继续验证。

每个账号最多保留四份凭证，新签发凭证的绝对有效期为三十天；使用令牌重连不延长有效期。升级前已签发的凭证保持原到期时间。新设备凭证会清理过期记录，达到上限时撤销最早到期的旧记录。登录 worker 完成后，主线程再次检查凭证是否被撤销/替换，防止“验证期间注销”的竞态。

客户端以服务器 URL 和账号为键保存在 `localStorage`，并记住该服务器最近成功登录的账户；现有 `sessionStorage` 凭证可迁移。刷新、关闭标签页和重新打开浏览器均可保留登录状态。存储不可用时退回当前页面内存，不保存密码。跨标签页直接读取最新凭证，其他标签页登出后不会继续使用缓存旧令牌。旧的手动自动登录开关已从设置界面移除。

主动登出会删除浏览器凭证，并通过已认证连接要求服务器撤销当前设备的记录。若开始页尚未连接，客户端使用待撤销凭据建立临时账户会话完成撤销，不生成角色；服务不可达时仍立即清除本机记录，远端撤销无法保证完成。普通断线、刷新和关闭网页保留凭据。恢复凭证属于账号认证，不属于世界、花朵、临时背包或数字玩家 ID，因此沙盒和玩法切换不改变登录身份。

`AccountLogin` / `AccountRegister` 只创建经过验证的账户会话，不指定世界、生成实体或发送 Welcome。点击开始后，现有账户会话发送 `EnterGame`；重新打开浏览器的开始页使用凭证发起正常登录，恢复保留身体或生成角色。未认证会话不能直接开始，重复开始不会重复生成身体。首次登录和过期凭证仍需账密验证，强制邮箱绑定流程保持有效。

JSON 与 MySQL 均保存验证摘要；临时沙盒账户不复制认证凭证。MySQL 更新凭证与账户快照共用事务。热重载玩家快照仅携带设备标识，用于恢复后的主动退出撤销，不包含原始令牌。

此方案不把设备标识当成秘密，也不把它称为硬件认证；恢复令牌本身是 bearer credential。公开部署仍使用 HTTPS/WSS，浏览器脚本上下文必须被保护。安全随机数、服务端到期/撤销、凭证不进入日志等边界参考 [OWASP Session Management](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。浏览器存储不能防御同源脚本执行，不能冒充 HttpOnly cookie 的保护。

离线验证入口：`FlorrBt_AccountTests`、`FlorrBt_Tests` 的认证协议回归、`node tools/test_auth_recovery.mjs`。测试数据仅在 `artifacts/`，不连接真实账号数据库。
