# 移动端 UI 与触控调整（按 Florr 参考图回调）

本轮只修改客户端；没有登录、发送游戏操作、重启服务端或进行手机实机验收。

## 修正的原因

- 原移动端把所有控件乘以最低约 0.566 的缩放倍率，36px 按钮会缩到约 20px；天赋节点等还会受到通用按钮高度规则影响。
- 摇杆外观随屏幕缩放，但计算速度和摇杆位移仍使用固定 62px 半径。
- 三个战斗按钮占用三行三列且整块区域拦截触摸，透明空白也会挡住操作。
- 触控动作原先没有进入键鼠使用的同一套指令分发；字母外观与动作分发应分开处理。
- 桌面拖拽没有区分 pointerId，滑动背包或另一根手指的移动/松开可能启动、移动或结束错误的拖拽。
- 软键盘通过平移整个 body 避让输入框，连画布与固定定位的操控层一起改变了坐标。

## 当前布局和操作

- 恢复左下角背包／天赋／合成和左上角设置／图鉴原有图标，移除上一轮新增的顶部导航和菜单。天赋点继续显示在原天赋图标上。
- 右侧仅保留无边框、半透明黑色圆形 A/B/X：A 攻击、B 防御、X 整排主副槽换装。A 较大居左，X/B 在右侧上下排列；不把字母解释成物理键盘的 A/B/X bind。
- 左侧触摸游戏画面才出现两个圆组成的摇杆，松开即隐藏，没有常驻提示文字。满速距离仍按实际圆盘和摇杆头尺寸计算，保留死区和连续加速。
- 卡槽恢复上一版主槽大、副槽小、左下角紧凑排列及折叠箭头，默认展开。撤回等尺寸全宽滚动条和两排滚动联动。
- HUD 恢复原宽度缩放比例；摇杆和 A/B/X 使用独立尺寸，保留正确命中区域。天赋树仍有触屏缩放按钮。
- 点槽位换装；长按槽位打开“换位 / 卸下 / 取消”，滑动不会触发长按。背包保留点击装备，触屏滑动不会启动桌面拖拽。桌面鼠标拖拽仍保留，并补上 pointerId 隔离。
- 移动和攻击、防御分别管理触点；松开其他手指不影响仍按住的动作。取消、失焦、旋转、打开面板及死亡会释放触控。
- 聊天恢复卡槽上方的聊天条及原输入框，撤回新增发送按钮、频道按钮和大块弹出背景，横屏不再隐藏聊天。软键盘遮挡时只抬高聊天框，不平移整个页面。
- 背包、合成、天赋恢复铺满可用视口的平面面板，去掉上一轮的悬浮圆角边框；保留安全区、动态视口及较宽横屏合成分栏。控制台仍保留手机可点的关闭入口。

触控动作使用内置指令（如 `attack`、`defend`、`swap`），以独立 `touch` 来源记录按住状态；不模拟 A/B/X，也不覆盖玩家保存的键鼠 bind。

## 验证范围

离线检查：

```text
node tools/test_mobile_ui.mjs
node tools/test_input_holds.mjs
node tools/test_craft_talent_ui.mjs
node tools/test_dev_debug.mjs
node tools/test_map_loading.mjs
node tools/check_client_deps.mjs
```

触控专项覆盖 A/B/X 动作映射、摇杆触摸显示、多指独立松开、方向/速度、取消与旋转释放、原 HUD 入口恢复、软键盘视口及三种语言键值。合成与天赋检查还覆盖触屏缩放按钮。
离线模拟不等于真实手机视觉和浏览器行为验收。请重点试：竖屏/横屏、主副槽展开/收起、多指移动加攻击、聊天键盘开关、背包滚动与长按槽位。

刷新网页即可加载前端修改；桌面可用 `mobile on` 临时观察触控布局，测试完用 `mobile auto` 恢复自动判断。不需要重新编译服务端。
