# FlorrBt v1.0.9

本次合并服务端生命周期与账户服务重构，以及 Web 客户端界面、渲染和交互调整。

- 登录后先同步账户和背包，点击“开始游戏”才创建玩家实体；支持记住登录、菜单断线恢复及退出登录撤销凭证。
- 重做开始页动态花瓣，按真实背包比例持续生成、移动和旋转。设置提供开启或关闭，关闭后不显示花瓣，不再保留静止版本。
- 收紧账户、背包、合成、天赋、图鉴等界面尺寸和文字布局；图鉴掉落使用固定间距。调整面板动画、天赋旋转及图鉴说明。
- 修复快速换装的显示与槽位同步，允许死亡期间编辑配装，改善同世界附身、复活与重连的场景同步；客户端使用服务端状态插值。
- 完善世界限定的扩展能力、NPC 临时背包、沙盒隔离、地形与密道规则、快照引用和有序帧处理；举报与邮件使用进程内网络传输。
- 增加 Discord、QQ 和邮箱绑定接口。Discord/QQ 应用参数保持为空；未配置的平台不会提供授权入口。

## Windows 部署

下载 `FlorrBtHotReload-v1.0.9.zip`，解压到独立目录后运行 `START_ALL.cmd`，默认通过 `http://服务器地址:8080` 访问。

部署包包含 Release 服务端与启动器、Node.js、MySQL 8.4 和所需运行库及许可文件。`PACKAGE_MANIFEST.json` 记录源码提交和核心二进制哈希，发布附件同时提供 ZIP 的 SHA-256 校验文件。

升级旧部署前先备份并保留原有 MySQL 数据目录、账户数据、`data/server.cfg` 和本地 OAuth/Web 配置。新包不携带正式账户、数据库、密钥或运行日志，不自动迁移旧数据。
